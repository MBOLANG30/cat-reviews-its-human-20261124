# Make the AI Judge Laugh: Cat Reviews Its Human

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990)

A make.fun bounty entry. The program writes one funny one-star review,
written by a house cat about its human, to `entry.txt`:

> One star. The food bowl was empty for four whole minutes. I have filed this under crimes and will be bringing it up at 3am.

Run it with `node main.ts`; it writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).
